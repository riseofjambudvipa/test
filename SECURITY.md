# Security Policy

## Supported Versions

We release patches and security fixes for the active major release versions of CapStudio:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

---

## Reporting a Vulnerability

The CapStudio team takes security and privacy seriously. CapStudio is designed as a **100% offline, privacy-first desktop and mobile application**. It does not collect telemetry, transmit private videos, or send transcribed text to external servers.

If you discover a security vulnerability or security-sensitive defect in CapStudio (such as insecure file system operations, command injection vulnerabilities in CLI invocations, or dependency CVEs):

1. **Do NOT open a public GitHub issue.**
2. Send an email report to `security@capstudio.ai` or submit a private security advisory through GitHub:
   * **GitHub Security Advisory**: Navigate to the **Security** tab of the repository and select **Report a vulnerability**.
3. Include detailed reproduction steps, the affected platform (Windows, macOS, Linux, Android, iOS, Web), and any proof-of-concept scripts or command lines.

### What to Expect

* **Initial Response**: We will acknowledge receipt of your vulnerability report within 48 hours.
* **Triage & Assessment**: We will assess the severity and determine the impact on users.
* **Resolution**: Once a fix is verified, a patched release will be published and an advisory will be credited to the reporter.

Thank you for helping keep CapStudio safe and private!
